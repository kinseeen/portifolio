## 📖 About the Project

This is my **final project** for *Noroff Vocational School*.  
The purpose of this assignment was to create a **personal portfolio website** to showcase my previous work and demonstrate my front-end development skills.

The portfolio is a **multi-page React application**, designed to highlight my earlier projects in a clean, accessible, and visually appealing way.

---
## 🧩 Featured Projects - 
 - CSS frameworks
 - Javascript frameworks
 - Semester project 2

Each project is displayed on the homepage with a preview card containing:
- 🏷️ Project title  
- ✏️ Short description  
- 🔗 “Read More” link (or a clickable project card) that redirects to a detailed article page

## 🧭 Website Structure

### 🏠 **Homepage**
The homepage features a grid of project teaser cards.  
Each card includes:
- Project title  
- Short teaser/description  
- A “Read More” link (or full clickable card) that takes you to the article page  

### 📄 **Article Page**
Each project has its own dedicated article page with:
- 🖼️ Project image  
- 🧠 Detailed project description  
- 🌐 Link to the **live site**  
- 💻 Link to the **GitHub repository (README)**  
- 📋 **Share/Copy link** button to copy the current page URL

## ⚙️ Built With

This project was built using the following technologies:

- [React](https://react.dev/) – JavaScript library for building user interfaces  
- [Vite](https://vitejs.dev/) – Lightning-fast frontend build tool  
- [Tailwind CSS](https://tailwindcss.com/) – Utility-first CSS framework for styling  
- [React Router](https://reactrouter.com/) – For client-side routing  
- [Node.js](https://nodejs.org/) – Runtime environment for npm and development tooling  
- [npm](https://www.npmjs.com/) – Package and dependency manager

## 🚀 Getting Started

### 🔧 Installation

1. Clone the repository:
   
   -  git clone https://github.com/kinseeen/portfolio.git

2. Navigate to project directory
   -  cd portifolio
  
3. Install dependencies
   -  Npm install

4. Run development server
   -  npm run dev

5. Open browser and visit
   -  http://localhost:5173/
